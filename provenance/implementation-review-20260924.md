# ワンビー食堂：実装・検証記録
確認日: 2026-09-24（JST）

## 対象と優先指示
対象は sample_food1 の静的サイト（dist）。ユーザー提供のPCデザインを再現し、SP表示を作成する。本文・価格・UIはHTMLとCSS、厨房・店内写真は承認画像から再構成した生成素材、OGPは添付原本をそのまま使う。

ユーザーの「noindexをいれ」を適用。「GA4はいったんなし」が先のGA4作成・タグ挿入依頼を取り消す。GA4プロパティは作成しておらず、解析コードも配信物に含めない。

参照規約はユーザー提供の AISEO_RULES.md と OneBe-AIO_RULES.md v2.0。実在店舗向けの必須項目や検索公開を前提とした項目を、架空・noindexのデモにそのまま当てはめて偽の情報を追加しない。
