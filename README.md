# サンプル — HAIR & TIME

架空のプライベートヘアサロン「サンプル」のレスポンシブサイト。

公開先: https://onebe-inc.github.io/sample_food1/

## デザイン

当初の参考サイトの完全複製ではなく、独自に書いたHTML / CSS / JavaScriptです。ユーザーの追加指示に従い、左右分割の導入、深緑・淡緑の配色、独自の見出しと情報構成、罫線を使ったメニュー一覧に変更しました。参照サイトのソース・写真・ロゴ・文章は公開ファイルに含めていません。

屋号・ロゴ文字・文章は本案件用に作成。掲載料金、所在地、記事はサンプルです。写真はストック素材であり、実在する当サロンの施術・施設を示しません。素材出典は ASSETS.md に記録。

## 操作

- スマートフォン用ナビゲーション
- メニュー詳細ダイアログ
- 当月から3か月分のカレンダー（月曜・過去日は選択不可）
- 希望日・時間・メニューの予約プレビュー
- お問い合わせの入力検証・プレビュー
- 記事・個人情報の取り扱いダイアログ
- キーボード操作、Escで閉じる、動きを減らす設定への対応

予約とお問い合わせはデモです。入力を送信・保存しません。実運用には予約サービスや問い合わせ先の接続、店舗情報とプライバシー文書の確定が必要です。

## 公開と確認

`dist/` がそのまま公開ファイルです。インストール・ビルド不要。

`node tools/validate.mjs` で参照、画像形式、アンカー、ダイアログ、JavaScript構文などを確認できます。

mainへのpushで `.github/workflows/pages.yml` がGitHub Pagesへ公開します。

Google Fonts（DM Sans / Noto Serif JP）を外部から読み込みます。写真はローカル配信。アクセス解析は含めていません。デモのため noindex を設定しています。
